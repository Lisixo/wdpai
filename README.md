# Nazwa projektu

Strona internetowa - pokazuje dane

## Funkcje

| Obszar | Co robi |
|---|---|
| Strona startowa | Krótki opis funkcji |

## Tech stack

| Warstwa | Technologie |
|---|---|
| Backend | PHP 8.3 |
| Serwer HTTP | Nginx |
| Konteneryzacja | Docker Compose |

## Szybki start

```bash
git clone https://github.com/Lisixo/wdpai.git
cd wdpai
docker compose up --build -d
```

Aplikacja: http://localhost:8080

## Struktura projektu

- docker - konfiguracja kontenerów
- public - kod źródłowy strony

## Zasady developmentu

- Branch dla każdej funkcji.
- Małe, logiczne commity.
- Sekrety wyłącznie w .env.
